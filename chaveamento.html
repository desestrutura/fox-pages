Chaveamento

Cole sua lista, sorteie as chaves e escolha o vencedor de cada confronto até sobrar um campeão, como num mata-mata de Copa do Mundo. Dá para ligar uma fase de grupos antes. O torneio fica salvo neste navegador para você continuar depois.

Exemplo

Atalhos: ← e → escolhem (no desempate, 1, 2 e 3), Shift+← e Shift+→ removem o item do torneio (o outro passa por W.O.), Backspace desfaz. Também dá para clicar no vencedor direto no chaveamento.

🏆
Campeão
Classificação para copiar Do campeão para os primeiros eliminados, sem os removidos. Dá para colar no Duelo de Posições para afinar a ordem.
